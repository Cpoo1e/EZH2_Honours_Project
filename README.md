# EZH2_Honours_Project
Repository for bioninformatic analysis of EZH2 targeting with EPZ6438 in G7 GSCs.
Contains Raw data, python script and galaxy pipline
1. Jupyter notebook contain core code used to plot both differential and Ven diagrams
2. Raw Sequencing data in a FastQ Format
3. Manipulated data containing differential scores and p-values
4. Gene List from different layers of filtering
